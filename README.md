# Digital Clock

A simple desktop digital clock written in Python. It displays the current time
in 12-hour format with seconds and the current date, refreshing every second.

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)

No third-party packages are required.

## Run

From the project directory, run:

```powershell
python clock.py
```

The clock opens in a non-resizable window. Close the window to exit.
